# Gallery UX refinement — 2026-10-31

## 現行追補 — 全14項目

コンセプトは「ページ内の画像を見比べ、必要なものだけを迷わず選んで保存し、結果を確認できる」。全14項目の対応表、検証の到達点と本人試用は [UX-COMPLETION.md](UX-COMPLETION.md) を正本にする。この追補を下の詳細案v1・実施履歴より優先する。公開・ストア申請は含まない。

- 500候補・12000要素で区切る取得に「続きの候補」を設ける。未選択候補は現在の取得分に入れ替え、前の取得分・DOMから消えた画像でも選択済みは残す。直前に増えたURLは「今回追加」で確認する。
- `source`寸法と`decoded`/`measured`寸法を分ける。元ページの密度補正された寸法を実画素数として使わず、未確認候補は最小寸法条件で除外しない。読み込み後に実寸を表示し、条件更新の操作を用意する。
- 同じimg/pictureの別候補を代表カードへまとめ、拡大・100%表示・前後移動・候補ごとの選択で比較する。「選択済み」は検索・条件・候補グループを無視し、全選択を表示する。
- 選択、条件、表示モード、details開閉、scrollとfocus起点をsessionに記録する。作業タブ再読み込み後に復元するが、ブラウザ終了や拡張自体の再読み込みをまたぐ復元は保証しない。
- 保存設定はdraftを編集し、適用で確定する。キャンセル・閉じる・Escapeは取り消し。最後の保存方法とフォルダだけを次の作業ページへ引き継ぎ、ページ名と形式は初期化する。
- 検索iconを入力から分離し、選択名にalt、寸法と保存状態を説明として関連付ける。カードのlabel内に拡大buttonを入れない。キーボード用保存移動buttonはoverlay表示とし、focus時に一覧の配置を動かさない。
- 再描画・別候補・前後移動・拡大を閉じた後にfocusを保つ。保存操作からは最後の候補へ戻す。同候補が消えた場合は近い候補へ戻す。
- 中断再試行は元batchの設定を明示する。別設定でやり直す場合は中断分だけの新規保存scopeとし、通常選択を保持する。元形式の拡張子は画像MIME等から補い、未確定の`.img`を画像形式名として扱わない。

自動確認で測れる状態・配置と、人間の理解・見比べやすさ・反復の扱いやすさを分ける。最終suite結果はQAとUX-COMPLETIONへ記録する。Chrome116は公式テスト版で基本動作を確認し、本人は提示した操作試用を「試して問題なし」と回答した。実OS pickerの利用有無と実VoiceOver、初回・反復の個別評価は未確認として残す。

## 現状と選定案

通常の取得完了も黄色い通知で、英語小見出し、説明、4入力、選択操作、寸法注記がグリッド前に常設される。未選択開始、全体クリックできるカード、非表示選択込みの件数、成功分のみ選択解除、中断再試行は残す価値。

| 案 | 同じ選択→絞込→保存の場面での違い | 判断 |
| --- | --- | --- |
| 現状維持 | 全条件をすぐ見られるが、画像より先に低頻度情報を読む | 比較基準 |
| 全面アイコン化 | 文字は減るが、解除・再試行などの意味を覚える負担が増す | 不採用 |
| 短いラベル＋段階表示 | 検索・画像・選択保存を常時表示し、条件/説明を必要時に開く | 採用。条件表示と復帰経路を保つ |

## 詳細案 v1

- ヘッダーはブランドと使い方。元ページのタイトル・domain、元ページを開く、再スキャンを一組にする。英語スローガンと重複説明を除く。
- 検索は常時。native detailsの「絞り込み」に最小幅/高さ/形式を格納。有効条件数、閉じても残る条件チップ、個別解除、一括リセットを用意。現行仕様では寸法未確認候補を残す説明を条件欄に置く。
- ヘルプは開閉式。選ぶ→必要なら絞る→保存、取得範囲と再スキャンの短い説明を置く。
- 画像と情報を選択labelにまとめ、native checkboxを維持。拡大・保存移動buttonはlabelの外に分離する。ファイル名、寸法/形式、保存状態はタッチでも常時確認できる。保存状態を色だけにしない。
- 通常メッセージは控えめな状態行。警告/エラーは区別。選択総数、非表示選択件数、batchの処理中/完了/中断と再試行を常時表示。
- 保存はsticky footerで主操作。選択枠/チェックの120–180ms反応、条件開閉の短いopacity変化、実処理に沿う進捗を用いる。グリッド再生成に入場演出を付けない。reduced-motionでは停止、forced-colors対応。
- 360pxで2列、200%相当の幅、44px操作領域、明示focus、detailsのEscape閉鎖とsummaryへのfocus復帰。外部アイコン/フォント/依存を追加せずローカルSVGを使う。
