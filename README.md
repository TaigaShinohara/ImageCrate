# ImageCrate

画像を確認して、必要なものだけ一括保存するChrome拡張。

仮名・初期版 v0.1.0。将来のOSS公開に向けた開発版です。公開配布・Chrome Web Storeへの申請は今回の作業に含みません。公開用名称の重複や商標は未確認です。

## Chromeへ読み込む

1. Chrome 116以上で `chrome://extensions` を開き、デベロッパーモードをONにします。
2. 「パッケージ化されていない拡張機能を読み込む」で、このリポジトリ内の **`extension/`** を指定します。
3. 通常のWebページを開き、拡張アイコンからImageCrateを開きます。
4. 画像を選択して「選択N件を保存」を押します。

更新済みのコードを試す場合は、保存が終わってから古い作業タブを閉じ、`chrome://extensions` のImageCrateの再読み込みボタンを押してください。その後、元ページで拡張アイコンを押して作業タブを開き直します。作業途中の状態復元を試すときは、拡張の再読み込みではなく**作業タブだけを再読み込み**します。

実サイトを使わず試せる [合成ページと5つの試用課題](docs/UX-COMPLETION.md#本人試用の準備) を用意しています。

画面下の「保存先 → 変更」で、保存する場所・まとめるフォルダ名・保存形式を指定できます。名前は最初はページ名です。空欄ならページ名を使い、使えない記号・長い名前を調整した実際の名前をプレビューします。

設定は「設定を適用」で反映します。キャンセル・閉じる・Escapeでは、編集中の名前・形式・選んだフォルダを取り消し、適用前の設定を保ちます。適用しただけでは画像の保存を開始しません。

保存形式は **元の形式 / JPEG（.jpg）/ PNG（.png）/ WebP（.webp）**。JPEG・PNG・WebPは端末内で画像自体を変換します。JPEGの透明部分は白背景、PNGとWebPは透明部分を保持します。アニメーションは1コマの静止画、SVGはブラウザが読み取った寸法の画像になります。同じ形式を選んだ画像も再エンコードし、画質やメタデータが変わる場合があります。アニメーション・元データを保持する場合は「元の形式」を選んでください。形式は作業ページ内で保持し、新しく開いた作業ページは「元の形式」から始まります。

**変換して保存するときは、どちらの保存先でも作業タブを開いたままにしてください。** 画像の配信元だけへのアクセス許可をChromeに求めます。失敗しても元形式へ勝手に切り替えず、中断として表示します。中断分の再試行は、開始時に選んだ形式と保存先を使います。

- **Chromeのダウンロード先**（初回設定）：`ImageCrate/<指定した名前>/` に保存。「元の形式」では追加のサイトアクセス許可は不要です。
- **選択したフォルダ**：「フォルダを選ぶ」で任意の場所を選び、その中の `<指定した名前>/` に直接保存。適用した保存方法と最後のフォルダをこの端末で覚えます。書き込み許可が必要なら設定から再確認してください。絶対パスは取得できないため、画面には選んだフォルダ名を表示します。新しい作業ページのまとめる名前は、そのページ名から始まります。

選択フォルダへの保存では、保存する画像の配信元だけへのアクセス許可をChromeに求めます。許可しなくても選択は残り、Chromeのダウンロード先に戻して保存できます。**この方式では保存が終わるまで作業タブを開いたままにしてください。** 再読込・終了時は警告し、再読込後は中断分を再試行できます。Chromeのダウンロード履歴には載りません。

同名フォルダはそのまま使い、同名ファイルは上書きせず別名で保存します。「今回の保存先」と形式は保存開始時に固定され、「中断分を再試行」も同じ設定を使います。「中断分を新しい保存として準備」では、中断した画像だけを別の先・形式で新しく保存できます。通常の選択は保持し、新しく保存する前に中断分の対象件数を表示します。取り消すと通常の選択保存へ戻ります。

ビルド・APIキー・アカウント登録は不要です。実行時の外部ライブラリ・サーバーは使いません。

## 実装済み

- ページ内の画像、レスポンシブ画像候補、遅延読み込み属性、CSS背景、open shadow DOMと同一オリジンframeの画像を取得。
- URLで重複を除き、同じimg/pictureの別候補をまとめて表示。「大きく確認」「確認・他N候補」から拡大・100%表示・前後移動・候補比較ができ、画像ごとに選択できます。
- 検索、最小寸法、形式で絞り込み。適用中の条件はチップで確認・解除。寸法未確認の候補を残し、画像の表示後に確認した寸法で条件を更新できます。
- 最初は未選択。「表示中を選択」、個別選択、全解除。「選択済み」は絞り込みや候補グループにかかわらず、前の取得分を含む全選択を表示します。
- 選択分だけをChromeのダウンロード先、または選んだフォルダへ保存。まとめるフォルダ名を指定可能。実際の完了・中断を追跡し、中断分を再試行。
- 保存形式を指定し、JPEG・PNG・WebPへ実変換。保存形式と実際の拡張子を対応させ、変換済みファイルも完了・中断を追跡。
- 成功分は選択解除。作業タブの再読み込み後も選択・表示条件・表示モード・開閉状態・戻り位置を復元します。再スキャンは現在のDOMから候補を入れ替え、選択した画像は保持。「今回追加」から新しい候補を確認できます。
- 500候補・12000要素の区切りを超える場合は「続きの候補」で進めます。未選択の候補は次の取得分へ切り替わり、選択済みは残ります。
- altによる選択名、寸法・保存状態の関連付け、キーボード用の「保存操作へ移動」と「画像一覧へ戻る」、拡大表示を閉じた後のフォーカス復帰を用意。
- アイコンと短いラベル、選択枠、保存進捗で状態を表示。詳しい説明は「使い方」から確認。動きを減らすOS設定に対応。

## 権限とプライバシー

- `activeTab` / `scripting`: 拡張アイコンを押したページのDOMを一時的に調べます。全サイト常時アクセスは要求しません。
- `downloads`: 利用者が選んだメディアの保存と、当拡張が開始したdownload IDの状態確認。
- `alarms`: Chromeの保存受付が未確定の間だけ、作業タブを閉じた後も照合を再開するための内部アラームを使います。未確定分が解消すると解除します。外部通信や定期通知のためには使いません。
- `storage`: ページ候補と処理状況をChromeのsession storageに保持。「元の形式＋Chromeのダウンロード先」は作業タブを閉じても受理済みの残りを継続し、終了後に消去。任意フォルダ方式と画像変換は作業タブで処理します。session情報はブラウザ終了で消去します。
- 適用した保存方法と選んだフォルダのハンドルは、IndexedDBの同じ記録に端末内で保持します。まとめるフォルダ名と保存形式は、新しい作業ページへ引き継ぎません。ページURLや画像URLを永続設定へ保存しません。使い終わったsession/batchのハンドルを整理し、適用済み・準備中・最後のフォルダは用途に応じて保持します。
- 任意のサイトへのアクセスは初期状態で付与しません。`optional_host_permissions` は選択フォルダへの直接保存と画像変換のための宣言で、利用者が保存する画像の具体的な配信元だけを許可します。許可はChromeの拡張機能設定で取り消せます。
- サムネイル表示は該当画像のホストにアクセスします。Refererは送信しません。
- 解析・テレメトリ・アカウント・クラウド送信なし。メディア取得時はその配信元への通信が発生します。
- 候補URLは認証用query等を含む可能性があります。session内に留め、Git・ログ・不具合報告へ貼らないでください。フィードバックは合成データで再現します。
- サイトの認証情報・Cookieを独自に取得する処理はありません。Chrome自身のdownloadはブラウザの既存セッションに従います。

## 制約

- 取得は今DOMに存在する内容です。自動スクロールやページ全体の巡回は行いません。スクロール・表示後に再スキャンしてください。
- 閉じたshadow DOM、別オリジンiframe、ページ内blob画像には未対応。CSS擬似要素の背景・canvasの描画は対象外。
- 元ページの寸法情報は密度指定等で実ファイルの画素数と異なる場合があります。候補画像を拡張側で表示するまでは「寸法未確認」とし、最小寸法を指定しても残します。表示後に確認した寸法で絞り込みを更新できます。
- 認証・Referer制限・URL失効などにより、プレビューや保存に失敗することがあります。元ページで見える画像すべての保存は保証しません。
- 選択フォルダへの直接保存では、別の配信元へのリダイレクトやサイト制限で取得できない場合があります。アクセスを自動で広げず中断として表示します。Chromeのダウンロード先へ切り替え、画像を選び直して新しく保存する方法も使えます。
- 「元の形式」は内容を変換しません。Chromeへの保存ではChromeが返す画像MIME、選択フォルダへの保存では画像MIME・既知の先頭署名から拡張子を補います。拡張子不明の候補で判別できなければ `.img` と形式不明表示を使います。拡張子が付いたことは、デコードや正常な画像であることの保証ではありません。形式指定時は実変換した形式の拡張子を使います。ZIP化は未実装です。
- 形式変換は元ファイル32MiB以下・2400万画素以下・縦横16384px以下・出力64MiB以下。画像は1件ずつ処理し、取得・変換が30秒進まなければ中断します。デコードできない画像や寸法不明のSVGは元の形式で保存してください。これらは保持データの制限で、Chrome内部の一時的なメモリ使用量を完全に制限するものではありません。

- Chrome設定・Web Store等、拡張を実行できないページは対象外。
- 1回の取得は最大500候補・12000要素で、続きの取得に対応します。DOM変更や取得情報の期限切れでは先頭から再スキャンし、選択済みは保持します。埋め込み画像には別途容量制限があります。
- 作業タブは各拡張で4つまで。元タブが移動した場合はそのページでアイコンを押し直してください。
- 選択は作業タブごとに500件まで。作業タブ全体で候補情報6MiB・session情報8MiBの予算を設け、容量不足は通知します。選択を減らすか使い終わった作業タブを閉じて再操作してください。保存される画像ファイルの容量制限とは別です。
- 作業状態はブラウザのsession内に限ります。ブラウザ終了や拡張自体の再読み込みをまたぐ永続復元は保証しません。
- Chromeの保存受付の照合は30秒を判定期限とします。未確定分を再確認する内部アラームはChrome116互換の1分遅延を使い、背景処理やOSスリープで実行が遅れる場合があります。30秒以内の結果表示を保証するものではありません。

## 開発・検証

Node.js 22以上:

```sh
npm test
npm run check
# ブラウザテストのみ開発依存が必要
npm ci
npm run test:browser
npm run test:ux
# 公式Chrome for Testing116実行ファイルを指定した最低版の基本確認
CHROME_EXECUTABLE="/path/to/chrome" npm run test:compat
```

ブラウザテストはインストール済みのChromeを、個人プロファイルとは別の一時プロファイルで起動します。テストコピーだけにlocalhostのhost権限を付け、合成ページで収集・UI・保存を検証します。配布manifestにはhost権限を追加しません。録画テストは共有APIの入力を合成streamへ差し替え、実際のMediaRecorderと保存処理を検証します。実picker・activeTabアイコン操作・OS音声の検証とは分けます。`CHROME_CHANNEL`でPlaywrightのchannelを変更できます。

全14項目の対応表、試用手順と今回の到達点は [docs/UX-COMPLETION.md](docs/UX-COMPLETION.md)。検証範囲と残件は [docs/QA.md](docs/QA.md)、体験と状態の設計は [docs/DESIGN.md](docs/DESIGN.md) を参照してください。Chrome116は公式テスト版で基本動作を確認しました。提示した操作試用について本人から「試して問題なし」と回答がありました。実OS pickerの利用有無・実スクリーンリーダーは未確認です。
